# Decision cheatsheet

| If you see this | Do this | Reason |
|---|---|---|
| No clear route from offer to desire | Write One Belief before prose | The draft lacks a shared mission |
| "New" with no meaningful contrast | Compare with the reader's known alternatives | Novelty must be understandable |
| An opening dominated by biography | Move the relevant difference and benefit earlier | The reader needs a reason to care |
| A strong promise followed by a long delay | Add relevant initial proof | Interest also creates skepticism |
| A wall of facts | Arrange situation → obstacle → evidenced consequence | ABT gives evidence a narrative job |
| Past failure treated as personal inadequacy | Explain the supported unresolved obstacle | The new route needs a credible reason to differ |
| The proposed cause exists only because the product solves it | Research or narrow the cause | Reverse-engineering is a hypothesis method |
| Anger unrelated to the mechanism | Remove it or establish the causal connection | Q5 must support the same argument |
| Urgency is merely a date | Explain what changes after it | Inertia needs a meaningful cost of delay |
| A forecast written as a fact | Restore uncertainty and its basis | A meeting date does not confirm an announcement |
| A resume without a reason to trust | Choose a truthful credibility storyline | Relevance matters more than credential volume |
| The mechanism is only a trademark | Explain the process without the name | Naming is not causal explanation |
| Price feels too high | Improve useful value before default discounting | Bonuses should remove real obstacles |
| "Free" requires payment | State the paid requirement and included items | Purchase terms must be intelligible |
| A close begs or shames | Present real choices and a clear next action | Pressure can create reactance |
| A refund is called zero risk | Specify the risk actually covered | Fee refunds do not remove usage consequences |

## Choose the next repair

| Reader's likely reaction | Primary question |
|---|---|
| "I've seen this already" | Q1 |
| "Why should I care?" | Q2 |
| "I don't believe the claim" | Q3 |
| "I've tried this before" | Q4 |
| "That doesn't explain the cause" | Q5 |
| "I'll come back later" | Q6, after checking the other doubts |
| "Why listen to you?" | Q7 |
| "I don't understand why it works" | Q8 |
| "What exactly am I buying?" | Q9 |
| "What happens if I decline or it doesn't suit me?" | Q10 |

## Credibility selection

| Available truth | Use |
|---|---|
| Comparable struggle and documented change | I've been in your shoes |
| Relevant insider access and a real sharing motive | Robin Hood |
| Relevant work and achievements | Expert |
| Several of the above | Combine without inventing a bridge |

## Source defaults, not laws

- Plan One Belief plus short Q1-Q7 answers in about 5-10 minutes; research may take much longer.
- Aim to answer Q1-Q2 on the first page of a full letter.
- Evaldo reports handling Q1-Q7 in roughly the first third; the supplied full letter interleaves several functions.
- The offer sequence is report → subscription → testimonials → high anchor → bonuses → stack → price → guarantee when the newsletter model fits.
- No optimal conversion rate, headline length, fixed number of proof items, or validated success threshold is supplied.

## Source-selection rules

- Exact question wording: use the book, not the supplied Spanish manual.
- Exact terms of Eccentric Millionaire: use the PDF version, not the commentator's alternate version.
- Named hope formula and underlying indicator process: use the direct lecture.
- Open-loop and micro-commitment analysis: label as third-party interpretation.
- Dangerous Retirement: use only the visible offer fragment; authorship is unconfirmed.
